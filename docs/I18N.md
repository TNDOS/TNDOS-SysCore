# 写作与本地化约定 Writing and localisation convention

2026-10-18 作者裁定。 Author's ruling. 从今天起生效。 Effective from today.

## 一 提交信息 Commit messages

**一行中文标题，一行英文摘要。** One Chinese subject line, one English summary.

英文那行以组件前缀开头，说明动了哪一块。 The English line starts with a component prefix saying what was touched.

```
文档：写作与本地化约定            docs: writing and localisation convention
修复：PCI 桥的 secondary bus 取错一个字节
                                  fix: PCI bridge read the wrong byte for the secondary bus
功能：驱动改成 load / start 两段式
                                  feat: split drivers into load and start phases
```

**不是逐句对照，是两行。** Not a sentence-by-sentence pairing -- two lines.

正文（如果有）用中文，讲清"为什么"。 The body, when there is one, is in Chinese and explains why.

## 二 文档 Documentation

**中文一篇、英文一篇，各自独立成篇。** One Chinese document, one English document, each written on its own terms.

**不做逐句对照。** No sentence-level parallel text.

理由：老外不干逐字对照。 Reason: native English technical writing is not produced by translating sentence by sentence.

英文那一份应该是**用英文写的英文文档**，不是中文的镜像。 The English version should read as a document written in English, not as a mirror of the Chinese one.

**两份按章节对应**，同样的编号、同样的标题顺序——这样读者能对上，但不用一句一句比。 The two correspond **by section**: same numbering, same heading order, so a reader can line them up without comparing sentence by sentence.

一份改了，另一份没改，是**允许的**，但要在该章节开头标一句"英文版滞后"。 It is acceptable for one to lag behind the other, provided the lagging section says so.

## 三 代码注释 Code comments

**只写中文。** Chinese only.

它们记录的是"为什么这么写"，而这个理由是用中文想的。 They record why the code is written this way, and that reasoning happens in Chinese.

需要英文的读者自己翻。 Readers who need English translate it themselves.

## 四 控制台输出 Console output

**保持 ASCII 英文。** Stays ASCII English.

屏幕是资源受限的运行时界面，不是文档。 The screen is a resource-constrained runtime surface, not documentation.

中文控制台输出要字库、字宽计算、编码转换，那是另一个工程。 Chinese console output needs fonts, width calculation and encoding conversion -- a separate project.

## 五 适用范围 Scope

```
提交信息   两行：中文标题 + 英文摘要
文档       中文一篇 + 英文一篇，章节对应，不逐句对照
代码注释   只中文
屏幕输出   只英文（ASCII）
标识符     只英文
```

**已有文档不追溯重写。** Existing documents are not retrofitted.

它们是历史记录，重写会丢掉当时的语境。 They are historical records; rewriting them would lose the context of the moment.
