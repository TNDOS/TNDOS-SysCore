# 写作与本地化约定 Writing and localisation convention

2026-10-18 作者裁定。Author's ruling. 从今天起生效。Effective from today.

## 一 双语句式 Bilingual sentence pattern

**凡是成句的文字，一律"中文 + 空格 + 英文"。** Every sentence is written as "Chinese, then a space, then English".

这包括文档、提交信息、设计说明、给用户的报告。 This covers documentation, commit messages, design notes and reports to the user.

不是"整篇中文 + 附录英文"，而是**逐句对照**。 It is not "Chinese document plus an English appendix" -- it is **sentence by sentence**.

一句话只讲一件事，中英各一遍。 Each sentence carries one idea, stated once in Chinese and once in English.

## 二 代码注释 Code comments

**代码注释只写中文。** Code comments are written in Chinese only.

理由是它们的内核是"为什么这么写"，而这个理由是用中文想的。 The reason is that they exist to record why the code is written this way, and that reasoning happens in Chinese.

需要英文的人自己去翻，不必由我们维护两份。 Anyone who needs English can translate it themselves; we do not maintain two copies.

## 三 控制台输出 Console output

**屏幕上的输出保持 ASCII 英文。** On-screen output stays ASCII English.

这条和上面两条不冲突：屏幕是资源受限的运行时界面，不是文档。 This does not conflict with the two rules above: the screen is a resource-constrained runtime surface, not documentation.

中文控制台输出需要字库、宽度计算和编码转换，那是另一个工程。 Chinese console output needs fonts, width calculation and encoding conversion -- that is a separate project.

## 四 为什么是"逐句"而不是"整篇两份" Why sentence-by-sentence, not two documents

两份全文会漂移。 Two full documents drift apart.

改了一处中文忘了改英文，读者不知道哪份是准的。 Change one Chinese sentence and forget the English one, and the reader cannot tell which is authoritative.

逐句对照时，**漂移是可看见的**——一句话少了它的英文，当场就能发现。 With sentence-by-sentence pairing, **drift is visible**: a sentence missing its English half is obvious on sight.

## 五 示例 Example

```
对：  这一层的存在理由只有一个：让文件系统不再依赖固件。
      This layer exists for exactly one reason: to get the file system off the firmware.

错：  这一层的存在理由只有一个：让文件系统不再依赖固件。
      （下面整段英文翻译）
      (a translated block of English follows)
```

## 六 适用范围 Scope

```
适用   docs/*.md、提交信息、设计说明、给用户的报告
不适用 代码注释（只中文）、屏幕输出（只英文）、标识符（只英文）
```

**已有文档不追溯重写。** Existing documents are not retrofitted. 它们是历史记录，重写会丢掉当时的语境。 They are historical records; rewriting them would lose the context of the moment they were written.
